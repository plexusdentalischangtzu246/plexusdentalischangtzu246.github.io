🎯 gitContext - Commit with the right identity every time

A local Windows desktop app for developers with more than one GitHub or GitLab account. gitContext sets the right name, email, and SSH key for each repository, so you stop committing as the wrong person.

🚀 What is gitContext?

gitContext is a simple, local application that runs on your Windows computer. It solves a common problem: when you have more than one GitHub or GitLab account, it's easy to accidentally commit changes using the wrong name, email address, or SSH key. For example, you might have a work account and a personal account. You clone a work repository, make a few edits, and commit — only to realize later that the commit shows your personal email address. That can expose private information, confuse your team, or break your contribution streak.

gitContext fixes this by remembering which identity belongs to which folder on your computer. You link a folder to an account once, and from then on, every Git action inside that folder automatically uses the correct name, email, and SSH key. It's like having a helpful assistant that never forgets which hat you're wearing.

💡 Why You Need gitContext

If you juggle multiple GitHub or GitLab accounts, you already know the pain. You might use different email addresses for different projects, or you might need to switch SSH keys depending on whether you're working on a client's repository or your own open-source project. Doing this manually is error-prone and annoying. You have to remember to run commands like git config user.email or update your SSH config before every commit.

gitContext eliminates that mental overhead. It sits quietly in your system tray and automatically applies the right settings whenever you open a terminal or a Git client in a linked folder. No more last-minute checks, no more "oops" commits, and no more embarrassing email leaks. It's especially valuable for freelancers, consultants, and anyone who contributes to both company and personal projects from the same computer.

✨ Key Features

  • Automatic identity switching: Assign a name, email, and SSH key to any folder. gitContext does the rest without you lifting a finger.
  • Works with GitHub and GitLab: Supports the two most popular platforms for code hosting and collaboration.
  • Local and private: All your data stays on your computer. No cloud sync, no accounts, no tracking. Your credentials never leave your machine.
  • Simple setup wizard: Add your accounts and link them to folders in just a few minutes, even if you're not a technical expert.
  • System tray integration: Runs quietly in the background and is always ready when you need it.
  • SSH key management: Store multiple SSH keys and let gitContext pick the right one for each repository.
  • Email protection: Avoid leaking your personal email address in work commits or vice versa.

⚙️ How It Works

  1. Download and install gitContext on your Windows computer using the link on this page.
  2. Open the app and add your accounts. For each GitHub or GitLab account, enter the name and email you want to use, and optionally paste in an SSH key.
  3. Choose the folders that belong to each account. For example, link C:\Projects\Work to your work account and C:\Projects\Personal to your personal account.
  4. That's it. From now on, whenever you use Git in those folders, gitContext automatically applies the correct identity. You don't need to change any settings or run any commands manually.

Frequently Asked Questions

Does gitContext work with other Git providers like Bitbucket?

gitContext is designed for GitHub and GitLab. Other providers are not officially supported at this time.

Is my data safe?

Yes. gitContext stores all information locally on your computer. Nothing is sent to the cloud, and the app does not collect any personal data.

Can I use gitContext with multiple computers?

gitContext is a local app, so you would need to set it up on each computer separately. Your settings are not synced between machines.

What happens if I move a folder to a different location?

You may need to update the folder link in gitContext. The app includes an easy way to reassign folders without losing your account settings.

Do I need to be a programmer to use gitContext?

You need to be comfortable using Git and a terminal or Git client, but you don't need to write code. The app has a simple graphical interface that guides you through the setup.
